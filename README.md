# Galaxy Charge Monitor

Galaxyの充電状態と、速度を制限している制御を読み取るアプリです。充電設定や温度保護を変更する機能はありません。

## 表示するもの

- 電池側の正味電力、電圧・電流・残量、電池・LRP・充電IC・USBなどの温度。
- 直接充電の状態・段階、入力電流と電池電流の制御上限、有効な制御の投票と採用結果。
- 実機の温度設定と復帰温度。45W・60WなどのLRP表を画面ON/OFF別に比較。
- 実機から取得した充電設定の全件一覧と検索。元のバイト列も表示。
- このアプリのセッション中の履歴グラフと、明示操作によるJSONの書き出し。
- 日本語・英語、Material 3の明暗テーマ、検索可能なライセンス一覧。

## 導入

1. [Releases](https://github.com/OneUI-Mods/GalaxyChargeMonitor/releases)から署名済みrelease APKをインストールします。
2. アプリを開き「Rootで接続」を押し、Root管理アプリで許可します。Xposed・Vectorへの登録や再起動は不要です。
3. 詳細な温度・制御と設定表が表示されます。RootなしでもAndroidが提供する基本情報は表示できます。

Android 15以降へインストールできます。詳細情報の解析対象はGalaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9・BZI9です。Android 16などでも存在する読取項目を表示しますが、取得範囲や表示内容は端末・ファームウェアによって異なります。見つからない値を別の端末の数値で補いません。

## 値の意味

電池側の電圧×電流は、USB入力電力や充電器の実測W数ではありません。入力側のICLと電池側のFCCも別の値です。45W/60Wの設定表は比較用で、現在どの表が有効かを測定W数から決めません。温度条件を超えたことと、実際に制御の投票が有効なことを分けて表示します。

設定の存在と、その分岐が現在使われていることは別です。配列番号と条件の対応が未確定の項目もあります。データの更新時刻と、今回読み取った値か保存済みの値かを表示します。設定表の保存先は、このアプリ自身の内部データです。

## 電力とデータ

監視はアプリ表示中だけ行い、バックグラウンドでは停止します。常駐サービスやWakeLockは使いません。取得間隔は調整でき、非充電中は10秒以上の間隔に抑えます。履歴は最大360点をメモリに保持し、停止区間を補間しません。

通信権限はありません。JSONは利用者が選んだ保存先にだけ書き出します。充電制御・システム設定・サービス・温度保護には書き込みません。
